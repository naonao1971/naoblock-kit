# プロダクトバックログ（naoblock-kit（2D・3D共通部品））

スクラムのやり方で、やりたいことを1か所にまとめる（2026-11-18 から。書き方は咲耶フットボールの docs/BACKLOG.md と同じ）。

- **上にあるほど優先が高い**。並べ替えはプロダクトオーナー（なおなお）が決める
- **ふと出たアイデアは、まず一番下に積む**。並べ替えはあとで
- **スプリント**＝その日の作業くらいの短さ。始めるときに上から何個かを選び、終わったら「済み」へ移す（日付・見積もり・PR番号を書く。見積もりはバックログの行のものをそのまま持っていく。バックログを通らずに直したものも、ちーちゃんが見積もりを書く。「—」は記録なし（3点で数える）。開発ボードが1週間に済んだ点数＝ベロシティを数えるのに使う）
- **見積もり**（ちーちゃん）：S＝1〜2時間・PR 1本／M＝半日・PR 1〜2本／L＝数日・PRを分けて進める
- **価値**（ちーちゃんが案を出し、なおなおが決める）：高＝遊ぶ人・読む人に直接効く、求められている／中＝あると良い／低＝中の整理・保留中。並べ替えは「価値が高くて小さいもの」を上に、が目安（最後に決めるのはなおなお）
- 遊んだ人・読んだ人からのアイデア（公式LINEなど）も、ここに積む。出どころを「なぜ」の欄に書く
